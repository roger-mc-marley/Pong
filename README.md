# Pong

Un piccolo Pong arcade realizzato con HTML, CSS e JavaScript.

## Avvio

Apri `index.html` nel browser.

## Controlli

- `W` / `S` o frecce su/giu: muovi la racchetta
- `Spazio`: servi
- `P`: pausa
- `R`: riavvia

## File

- `index.html`: struttura della pagina
- `styles.css`: interfaccia e stile arcade
- `script.js`: logica di gioco
- `pong-spiegazione.excalidraw`: schema esplicativo
